# Glossary

## Terms and definitions

| Preferred term | Definition | Variants to avoid |
| --- | --- | --- |
| BIBIT gateway | The third-party payment gateway for premium collection and claims payment | payment provider, Bibit |
| CIS | Customer Information Service: the new shared service for customer, contact and policy-summary data | Customer Master, customer hub |
| Claims handling modernisation | This solution: the Handle Claim process and the services, integrations and document management behind it | claims transformation, Claims Hub, new claims system |
| Claims InfoServ | Claims Information Service: the new shared service that owns claim state, valuation, routing rules and audit trail | Claims Info Service, claims engine |
| CRM System | KCM's customer relationship management application, where staff work claims and requests | CRM platform |
| Document management system | Stores claim documents, indexed by claim | DMS, EDRMS |
| Financial Application | The Home & Away Financial Application: premiums, claims payment and the general ledger | FinApp, finance package |
| Handle Claim | The claims process: Register, Accept, Valuate, Pay | — |
| KCM | Kiwi Cover Mutual | — |
| PDM-01 to PDM-04 | The four Policy Data Management transactions exposed as services | — |
| Policy Data Management | The mainframe policy administration application inherited from ArchiSurance; system of record for policies and the claims ledger | PDM system, policy admin system |
| UNIX server farm | The virtualised RHEL estate in KCM's Wellington data centre | UNIX farm, server estate |
