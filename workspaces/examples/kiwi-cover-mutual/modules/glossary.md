# Glossary

## Terms and definitions

| Preferred term | Definition | Variants to avoid |
| --- | --- | --- |
| ARB | Architecture Review Board — approves high-level designs | — |
| ArchiSurance | The insurer KCM merged with in 2014; the name survives on the inherited Policy Data Management platform and some legacy domains | — |
| BIBIT gateway | The third-party payment gateway KCM uses for premium collection and, after this initiative, claims payment; its contracted name is under Operational accounts and licenses | payment provider, Bibit |
| C&A | Certification and Accreditation — KCM's security sign-off process before a solution handles member data in production | — |
| CICS | The mainframe transaction environment that runs Policy Data Management's transactions | — |
| CIS | Customer Information Service — the new shared service that holds and serves canonical customer, contact and policy-summary data | Customer Master, customer hub |
| Claims handling modernisation | This solution: the single Handle Claim process and the shared services, integrations and document management that support it | claims transformation, Claims Hub, new claims system |
| Claims InfoServ | Claims Information Service — the new shared service that owns claim state, valuation, routing rules and the audit trail | Claims Info Service, claims engine |
| CRM System | KCM's customer relationship management application, where staff register and progress claims and policy requests | CRM platform |
| Design Authority | The governance body that approves detailed designs as build-ready | — |
| Document management system | The system that stores claim documents and their metadata, indexed by claim, for every Handle Claim step to read | DMS, EDRMS |
| Financial Application | The Home & Away Financial Application: KCM's financial system for premiums, claims payment and the general ledger; its verified contracted name is in Software and licences | FinApp, finance package |
| Handle Claim | The end-to-end claims business process: Register, Accept, Valuate, Pay | — |
| Home & Away | KCM's product family for home, contents and motor cover; also the name of the Financial and Policy Administration applications that serve it | — |
| Insurant | ArchiMate's term for the insured party — the member | — |
| KCM | Kiwi Cover Mutual | — |
| MQ | The message-queuing middleware used to reach mainframe transactions | — |
| NAS | Network-attached storage — the file server used for batch files in the UNIX server farm | — |
| NFR | Non-functional requirement | — |
| PDM-01 to PDM-04 | The four Policy Data Management transactions exposed as services: policy lookup, insured-item lookup, policy create, claim ledger update | — |
| PIA | Privacy impact assessment | — |
| Policy Data Management | The mainframe policy administration application (the Home & Away Policy Administration component in the diagrams), the system of record for policies and the claims ledger | PDM system, policy admin system |
| RPO / RTO | Recovery point objective / recovery time objective | — |
| SAD / SSAD | Solution Architecture Document / Solution Support Architecture Document | — |
| SOAP | Solution on a Page — the shaping document approved before high-level design | — |
| Take out insurance | The policy intake business process: request received, processed, premium collected | — |
| UNIX server farm | The virtualised RHEL estate in KCM's Wellington data centre that hosts the CRM System, the Financial Application and the shared services | UNIX farm, server estate |
